Парсер товаров - это небольшой проект, созданный с целью сохранения истории цен на продукты. В качестве сайта с адекватными ценами в 2017 году был выбран online магазин utkonos.ru. После этого в связи с невозможностью парсинга сайта utkonos, так как там контент загружается с помощью javascript, парсятся цены с сайта globus.ru. Проект создан так, что можно легко добавлять новые сайты для парсинга.
